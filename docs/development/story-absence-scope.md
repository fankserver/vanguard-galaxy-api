# Absent-author qualification scope

`-StoryAbsentProbe -StoryDonorRoot <completed story sandbox>` selects a separate
Full process containing neither author assembly. SaveA must be the donor's
`Saves/qa-story-active.save`. Prepare requires the donor's successful story and
new-game receipts and successful process outcome; hashes bind the copied fixture
and original donor bytes. Standard preservation guards include that donor folder.
The six API/harness binaries still require the current reviewed revision.

Only the native save is copied, not relocated API generation files. This proves
protection of persisted native objects when both authors and associated API state
are unavailable; it does **not** prove cross-directory migration of owner data.
The probe requires exactly two reserved-namespace native missions, checks both
plugin and loaded-assembly absence, then drives guarded native update/forced
claim paths before and after a save/reload. Rewards, held-object identity and
native serialized content must remain unchanged. It never edits native objectives
or fabricates completion events.

Minimum launcher lifetime: 2100 seconds (ordinary Full allowance plus300 for
initial readiness and one readiness-settled reload). Migration qualification and
complete owned-story acceptance remain separate required work.
