# Synthetic wire fixtures

These files exercise the controlled qualification driver's real Unity HTTP/TLS, redirect and feed-parser paths. They are not release announcements, do not describe an installable package, and are never included in the API distribution. Production metadata must not point here.

The driver fetches an exact committed revision, validates its own synthetic GUID/channel/version, and records statuses without URLs or redirect query strings. `oversized.json` deliberately exceeds the 16 KiB bound; `invalid.json` deliberately uses an unsupported schema. No player data or proprietary references are present.
